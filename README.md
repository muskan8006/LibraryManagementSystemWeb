# Library Management System

A modern Library Management System built using Spring Boot, PostgreSQL, Thymeleaf, and Maven.

## Features

- Add Books
- Search Books
- Delete Books
- PostgreSQL Database Integration
- Modern UI Dashboard
- Responsive Design

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Thymeleaf
- Maven
- HTML/CSS

## Project Structure

src/main/java/com/library

- controller
- dao
- model
- util

## Run Project

```bash
mvn spring-boot:run
